## 📚 附录 · 深度解读

### 1. DeepSeek-V4-Flash 公测：低价 agent 底座

> 来源：[Artificial Analysis](https://artificialanalysis.ai/models/deepseek-v4-flash) · [explainx](https://explainx.ai/blog/deepseek-v4-flash-0731-codex-responses-api-july-2026) · 重要度 8/10

- **事件背景**：DeepSeek 于 7/31 将 V4-Flash（0731）API 推入公测，架构与此前 V4-Flash-Preview 一致——284B 总参数、约 13B 激活、1M token 上下文、纯文本，但通过重训在自家 agentic harness 上显著提升，并新增原生 OpenAI Responses API 支持与完整 Codex 兼容。定价为输入 $0.14、输出 $0.28 每百万 token（按缓存命中的混合口径更低）。
- **产业影响**：这是"低价 + agent/编码可用"这一细分的又一次加码。与本周 GPT-5.6 Luna 降价、Kimi K3 落地叠加，说明竞争正集中到"够用、便宜、易接入 agent 工作流"的中低端主战场。
- **竞品对位**：直接对位 GPT-5.6 Luna（低价档）与其他开源低成本模型；原生 Responses API/Codex 兼容降低了从 OpenAI 生态迁移的成本，是其争取开发者的关键抓手。
- **PM 视角启示**：高频、结构化、对延迟不敏感的 agent/编码任务，可把它纳入低价候选池，用"质量够用 + 成本更低"换毛利。
- **机会信号**：模型间 API 格式趋同（Responses API/Codex 兼容）让"多模型可切换"更容易，利好做模型路由与成本优化的中间层。
- **建议行动**：
  - 本周在编码/agent 场景用 V4-Flash 与 GPT-5.6 Luna 做质量与成本对比。
  - 若已用 Responses API/Codex，评估把部分低复杂度流量切过去的可行性。

### 2. AMD MI355X 跑 Kimi K3 的每美元性能胜过 NVIDIA B300

> 来源：[SemiAnalysis InferenceX](https://inferencex.semianalysis.com/compare/kimi-k26-b300-vs-mi355x) · [Startup Fortune](https://startupfortune.com/amds-mi355x-undercuts-nvidias-b300-on-cost-to-run-chinas-kimi-k3/) · 重要度 8/10

- **事件背景**：据 SemiAnalysis InferenceX 基准，在运行 Moonshot 的 2.8T 参数 Kimi K3 时，NVIDIA B300 节点的聚合吞吐仍领先约 1.65×，但其价格约为 2.4×，因此 AMD MI355X 在每美元性能上明显胜出（约 $2.50/GPU-hr 对 $6.00/GPU-hr）；两者均为每 GPU 288GB VRAM，这对运行如此大的模型至关重要。
- **产业影响**：这是 AMD 在推理经济性上"对 NVIDIA 最清晰的一次胜利"，把上周 AMD 与 Anthropic 的 50 亿美元合作从"战略意向"落到了"具体基准数据"，为算力供应多元化提供了实证支撑。
- **竞品对位**：NVIDIA 仍在原始吞吐上领先，护城河未破；但在"够用吞吐 + 更低单位成本"的推理场景，MI355X 成为可认真评估的替代项，尤其适合大参数开源模型的自托管。
- **PM 视角启示**：推理成本的下行不只来自模型变小/降价，也来自硬件竞争；中期成本预测应把"硬件侧降价"作为独立变量纳入。
- **机会信号**：跨硬件栈的推理适配、性能调优、成本对比工具，会随双供应商格局成熟而出现需求。
- **建议行动**：
  - 若有可观的大模型推理支出，让基础设施团队对 MI355X 做一次 perf/$ 实测。
  - 在成本模型中为"硬件侧价格竞争"预留下行情景。
